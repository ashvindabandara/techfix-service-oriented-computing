# TechFix Service-Oriented Computing System

A service-oriented computing solution developed for TechFix, a local computer shop, to improve supplier procurement, product availability, quotation management, and ordering processes.

## Project Overview

TechFix previously faced challenges with manual supplier quotations, inconsistent pricing and discounts, limited inventory visibility, inefficient ordering, and disconnected data sources.

This project implements a Service-Oriented Architecture (SOA) approach by integrating supplier services with a centralized TechFix backend and a client application.

## Main Components

- Supplier API 1
- Supplier API 2
- TechFix Backend API
- TechFix Frontend
- Supplier 1 Database
- Supplier 2 Database

## Key Features

- Supplier API integration
- Centralized product and supplier information
- Product quotation management
- Inventory availability checking
- Order placement
- Supplier communication through APIs
- Client application for TechFix staff
- Database-driven service architecture

## Technologies Used

- C#
- .NET / ASP.NET
- RESTful APIs
- SQL Server
- Visual Studio
- Service-Oriented Architecture (SOA)
